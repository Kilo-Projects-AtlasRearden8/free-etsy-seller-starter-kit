# Free Etsy Seller Starter Kit

Fillable, printable, no account needed. Credit **Asdale Dynamics, LLC**.

A no-cost starter kit for new Etsy sellers: shop policies, listing worksheet,
pricing calculator, packaging slip, and income log. Every page is designed to
be filled in on screen or printed by hand — no signup, no tracking, nothing to
buy.

## What's inside

| File | What it's for |
|------|---------------|
| `shop-policies.md` / `shop-policies.html` | Fill-in shop policies (processing times, shipping, returns, FAQ) |
| `listing-worksheet.md` / `listing-worksheet.html` | Prep a listing before you publish: title, tags, photos, details |
| `pricing-calculator.md` / `pricing-calculator.html` | Work out materials, labor, fees, and a profitable price |
| `packaging-slip.md` / `packaging-slip.html` | Print-and-fill slip to tuck into every order |
| `income-log.md` / `income-log.html` | Track sales, fees, and net income by month |

## How to use

1. Open any `.html` file in your web browser (Chrome, Firefox, Safari, Edge).
2. Fill in the fields on screen, or print the page and write by hand.
3. To print: press **Ctrl+P** (or **Cmd+P** on Mac). Each page has print styles
   that hide form borders and controls so your printout looks clean.
4. Save a copy for your records. Nothing is sent anywhere — everything stays
   on your computer.
